{% if help == "coauthors" %}

Une publication de n auteurs compte 1/(n − 1) dans le lien de chaque paire de ses auteurs : deux auteurs d'un article à deux sont plus liés que deux auteurs d'un article à vingt. Plus un lien est fort, plus ses auteurs sont rapprochés.

Survolez un auteur pour voir son nom ; cliquez pour le sélectionner, double-cliquez pour ouvrir sa fiche. Échap ou un clic dans le vide désélectionne.

{% elif help == "keywords" %}

Deux {{ terms.plural }} sont reliés quand une même publication les porte ; plus elles sont nombreuses, plus le lien est épais et plus ils sont rapprochés. Seuls les noms des plus gros tiennent sans se chevaucher : zoomez pour lire les autres.

Survolez un {{ terms.singular }} pour voir son nom ; cliquez pour lister ses publications, double-cliquez pour les ouvrir dans « Mon corpus ». Échap ou un clic dans le vide désélectionne.
